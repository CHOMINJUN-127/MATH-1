# Triangle Trigonometry Verification

## 📌 프로젝트 개요

이 프로젝트는 학교에서 진행한 **수학 주제탐구 발표**를 준비하는 과정에서 제작되었다.
당시 학습하고 있던 단원이 **삼각함수**였기 때문에, 교과서에서 배우는 개념을 단순한 계산에 그치지 않고 **실제 상황에 적용해 보고자** 이 주제를 선택하였다.

삼각함수는 거리와 각의 관계를 통해 위치를 추정할 수 있기 때문에, 이를 활용하면 **GPS와 같은 위치 추적 원리**를 수학적으로 설명할 수 있다고 판단하였다. 특히 여러 삼각함수 중에서도 **코사인 법칙은 두 거리와 그 사이의 각이 주어졌을 때 나머지 한 변을 계산할 수 있어,** 위성과 사용자 사이의 거리 계산에 효과적으로 활용할 수 있다.

이에 따라 본 프로젝트에서는 삼각형 구조를 가정하여 위성 A, 위성 B, 사용자 위치를 점으로 설정하고, **코사인 법칙과 사인 법칙을 이용해 각과 거리의 관계를 계산**하였다. 또한 이러한 수학적 계산 과정을 **파이썬 코드로 구현**하여 결과를 수치적으로 검증하고, 계산된 값이 실제 삼각형 구조와 일치하는지를 **기하적 시각화**를 통해 확인하는 것을 목표로 한다.

## 🎯 문제 설정

본 프로젝트에서는 GPS 위치 계산의 원리를 단순화하여, 한 평면 위의 삼각형 구조로 문제를 설정한다.
위성 A와 위성 B, 그리고 사용자 위치를 각각 삼각형의 세 꼭짓점으로 가정하고, 이들 사이의 거리와 각의 관계를 삼각함수로 분석한다.

구체적으로, 위성 A와 사용자 사이의 거리와 위성 B와 사용자 사이의 거리 중 일부 값이 주어져 있으며, 위성 A에서 관측되는 두 방향 사이의 각이

이를 위해 **사인 법칙과 코사인 법칙을 각각 적용**하여 동일한 값을 얻을 수 있는지를 확인하고, 두 서로 다른 수학적 접근이 **같은 결과로 수렴함을 검증**하는 것을 핵심 문제로 설정한다. 또한 계산된 결과가 실제 삼각형 구조에서도 타당한지를 확인하기 위해, 파이썬을 이용한 **기하적 시각화**를 함께 수행한다.

## 🧠 접근 방법

이 프로젝트에서는 삼각형의 변과 각 사이의 관계를 분석하기 위해 **삼각함수의 기본 정리인 사인 법칙과 코사인 법칙을 핵심 도구로 사용**하였다.
단순히 하나의 공식을 적용해 값을 구하는 것이 아니라, **서로 다른 두 접근 방법이 동일한 결과를 도출하는지 검증**하는 방식으로 탐구를 진행하였다.

먼저, 주어진 각 ∠𝐴=60∘ 와 두 변의 길이를 이용하여 **사인 법칙**을 적용하고, 이를 통해 각 𝐵의 사인 값을 계산한다. 이후 이 값을 제곱하여 sin²B를 구하고, 
삼각함수의 기본 항등식

<img width="254" height="76" alt="image" src="https://github.com/user-attachments/assets/50a98271-0d24-45dd-b6d6-7b7684ac2020" />

을 이용해 cos²B를 도출한다.

다음으로, 동일한 삼각형에 대해 **코사인 법칙**을 적용하여 한 변의 길이를 먼저 계산한 뒤, 이를 다시 활용해 각 B의 코사인 값을 직접 구한다. 이 과정에서 얻은 COS² B 가 앞선 방에서 계산한 값과 일치하는지를 비교함으로써, 두 수학적 접근이 같은 결론에 도달함을 확인한다.

모든 계산 과정은 **파이썬으로 구현**하였으며, 실수 연산으로 인한 오차를 최소화하기 위해 가능한 경우 **분수 형태의 계산**을 유지하였다. 또한 계산된 결과를 turtle 모듈을 사용해 삼각형으로 시각화하여, 수치적 결과가 기하적 구조와도 일치함을 직관적으로 검증하였다.

## 🐢 기하적 시각화

<img width="960" height="810" alt="image" src="https://github.com/user-attachments/assets/a5c179ca-6371-4ed3-9f30-13bbe5fa8cc4" />

위 그림은 본 프로젝트에서 설정한 삼각형 구조를 turtle 그래픽을 이용해 시각화한 결과이다.
위성 A, 위성 B, 사용자 위치를 각각 점으로 표현하고, 이 세 점을 연결하여 **삼각형 형태의 거리 관계**를 직관적으로 나타냈다.

점 A(위성 A) 는 기준점으로 설정하여 사용자 위치와 수평선상에 배치하였고,
점 B(위성 B) 는 각 **∠A=60∘** 조건을 만족하도록 위치시켰다.
이를 통해 위성 A–사용자–위성 B 사이의 거리와 각의 관계가 **문제 설정에서 가정한 삼각형과 동일함**을 시각적으로 확인할 수 있다.

이 시각화는 앞서 계산한 사인 법칙과 코사인 법칙의 결과가
단순한 수치 계산에 그치지 않고, **실제 기하 구조에서도 성립함을 검증**하기 위한 목적으로 사용되었다.
즉, 파이썬을 이용한 기하적 표현을 통해 수학적 계산 결과가 **공간적 관계와 일관됨**을 확인할 수 있다.

## 🛠 사용 기술

### Python

삼각함수 계산 과정과 수학적 검증 절차를 코드로 구현하기 위해 사용하였다.
계산 과정을 단계별로 표현할 수 있어 수식 전개와 코드의 대응 관계를 명확히 나타낼 수 있다.

### math 모듈

sin60∘, cos60∘ 와 같은 삼각함수 값 계산과 각도의 라디안 변환에 사용하였다.
기본적인 삼각함수 연산을 정확하게 처리하기 위해 활용하였다.

### fractions.Fraction

실수 연산으로 인해 발생할 수 있는 오차를 방지하기 위해 분수 형태의 계산을 유지하였다.
이를 통해 12/25 , 13/25 와 같은 결과를 **정확한 유리수 값**으로 표현할 수 있었다.

### turtle 그래픽 모듈

위성 A, 위성 B, 사용자 위치를 점으로 표현하고 삼각형 구조를 시각화하기 위해 사용하였다.
계산된 수학적 결과가 실제 기하 구조에서도 성립함을 직관적으로 확인하는 도구로 활용하였다.

## 📌 활용 가능성

본 프로젝트는 삼각함수의 이론적 계산을 실제 상황에 적용한 사례로, **수학 개념을 단순 암기가 아닌 문제 해결 도구로 활용**하는 학습 자료로 사용할 수 있다.
특히 사인 법칙과 코사인 법칙을 각각 적용하고 그 결과를 비교·검증하는 과정은, 삼각함수 단원의 핵심 개념을 깊이 이해하는 데 도움이 된다.

또한 본 프로젝트는 **GPS 위치 계산의 기본 원리를 삼각형 모델로 단순화한 구조**이므로, 위성 위치 추적, 거리 측정, 공간 좌표 계산과 같은 주제로 확장할 수 있다.
변의 길이나 각의 값을 변경하며 다양한 조건을 실험함으로써, 실제 환경에서 삼각함수가 어떻게 활용되는지를 탐구하는 데에도 적합하다.

나아가 본 프로젝트는 현재의 **2차원 삼각형 기반 모델**에서 더 발전시켜,
삼각함수를 이용한 위치 계산을 **3차원 공간으로 확장하는 것을 목표**로 한다.
이를 통해 위성 위치와 사용자 위치를 입체 좌표로 표현하고,
장기적으로는 **구글 어스나 내비게이션과 유사한 3D 위치 시각화 시스템**으로 구현하는 것을 목표로 한다.

이와 같은 확장은 평면 삼각형에서의 계산이 실제 공간 좌표 계산으로 어떻게 연결되는지를 보여 주며,
수학·물리·프로그래밍이 결합된 **공간 정보 처리 모델**로 발전시킬 수 있는 가능성을 가진다.
